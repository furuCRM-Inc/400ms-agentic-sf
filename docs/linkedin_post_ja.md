AIエージェントが「考え中…」を20秒続けている間に、VIP顧客は解約ボタンを押していた。

私たちはそれを400ミリ秒に縮めた。

────────────────────

🐌 従来のAIエージェント

0ms    顧客「$50,000の損失。今すぐ返金しろ！」
500ms  画面をスクリーンショット
2,000ms LLMが画面を「読む」
5,000ms 返答を1トークンずつ生成中…
12,000ms ボタンを探してクリック
20,000ms ✅ ようやく完了

顧客はとっくに冷めている。

────────────────────

⚡ Jev + WebMCP

0ms   顧客「$50,000の損失。今すぐ返金しろ！」
50ms  Jevが構造化判断を出力（テキスト生成なし）
250ms WebMCPが返金処理を直接実行
400ms ✅ 完了。謝罪メッセージ送信済み。

担当者がメッセージを読み終わる前に解決している。

────────────────────

何が違うのか、2行で言うと：

① Jevは「考えない」——判断結果だけを50msで返す
② WebMCPはUIを「見ない」——コンポーネントがAIに自分を直接呼ばせる

```javascript
// LWCが自分自身をAIツールとして宣言する
document.modelContext.registerTool({
  name: "approve_refund",
  execute: async (args) => ApexController.approveRefund(args)
});
```

エージェントは画面スクリーンショット不要。
DOM探索不要。
ただツール名を呼ぶだけ。

────────────────────

「エージェントが勝手に返金するのは危険では？」

安全です。
WebMCPのツールは開発者が明示的に登録する。
Apexは既存のSalesforceセキュリティ（FLS・プロファイル権限）に従って動く。
新しい権限は一切ない。
